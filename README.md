# VIMO Frontend

Expo SDK 58 기반의 앱입니다. 유저·관리자 화면을 하나의 프로젝트에서 실행합니다.

- 저장소: [vimo-platform/vimo-frontend](https://github.com/vimo-platform/vimo-frontend)
- 작업 브랜치: **`appdev`**

## 처음 실행하는 경우

**[처음 실행하기 가이드](docs/GETTING_STARTED.md)**를 순서대로 따라 하세요.

프로그램 설치, Git Clone, `main` → `appdev` 전환, `npm install`, Expo 계정 로그인, SDK 58용 Expo Go 설치, QR 접속, VIMO 테스트 계정 로그인을 안내합니다.

## 프로젝트 구조

[폴더 구조 안내](docs/PROJECT_STRUCTURE.md)를 참고하세요. 앱 명령어는 `package.json`이 있는 저장소 최상위 폴더에서 실행합니다.
